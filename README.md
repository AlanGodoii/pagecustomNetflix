## Sobre o projeto

Projeto desenvolvido para a disciplina de Front-End com o objetivo de reproduzir
a página inicial da Netflix utilizando HTML e CSS, e automações com java

O projeto será desenvolvido utilizando HTML semântico, CSS responsivo,
Flexbox, Grid e boas práticas de acessibilidade.
